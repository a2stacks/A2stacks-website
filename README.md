## ✦ Key Design & Animation Features

- **Ultra-Luxury Light & Dark Mode Engine**: Intelligent system-default detection (`prefers-color-scheme`) with smooth 0.4s cubic-bezier physics, zero-FOUC preloading, and manual toggling via header and mobile drawer. Light mode features warm cashmere alabaster (`#f6f5f0`), burnished French gold leaf, and deep obsidian typography.
- **Cinematic Film Opening Experience**: Anamorphic dual-shutter theatrical intro with gold monogram shimmer, hud telemetry, and ESC/click skip.
- **Interactive Cyber Mascot Companion & Studio Chatbot**: SVG android companion with animated hand-wave, contextual section-aware speech bubbles, and embedded conversational assistant with studio knowledge base.
- **Precision Process Pipeline**: 4-phase execution blueprint with animated flow ribbon, gold/cyan/emerald top neon bars, duration estimates, bespoke iconography, and core deliverable checklists.
- **Dynamic Interactive Canvas**: Real-time celestial constellation and luxury starfield with cursor proximity reactions.
- **Dual-Ring Custom Cursor**: Smooth interpolated trailing glow with expansion over interactive nodes.
- **Mouse Spotlight Cards**: Dynamic radial spotlight border that follows the cursor across grid surfaces.
- **3D Perspective Tilt Physics**: Hardware-accelerated hover tilt on the interactive tech console and founder cards.
- **Interactive Tech Console**: Auto-typing terminal simulator with tab switching (`system.ts`, `ai_agent.py`, `metrics.json`).
- **Interactive CADLAB Preview Switcher**: Live tab switching between Overview, Performance Audit (100/100 Lighthouse), and Stack Breakdown.
- **Project Initiation Suite**: Dual-action client inquiry system supporting structured email dispatch and 1-click WhatsApp transmission.
- **Live Studio IST Clock**: Real-time Angul, Odisha timezone indicator.
- **Complete SEO Suite**: Google/Bing indexing ready with JSON-LD `ProfessionalService` schema, Open Graph, Twitter cards, Geo/ICBM tags for Odisha, `robots.txt`, and `sitemap.xml`.
- **Full-Spectrum Responsiveness**: Pixel-perfect layout optimization for desktop (1440px+), laptop (1024px-1200px), tablet (768px-1024px), and mobile (320px-600px).
- **Zero-Dependency Architecture**: Built with pure vanilla HTML5, modern CSS3, and ES6+ JavaScript for 60/120 FPS performance and zero build-step overhead.
